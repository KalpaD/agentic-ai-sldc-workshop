# Sunrise Bakery — website

A one-page website for a small family bakery.

## Stack

- One page: `index.html`
- Plain CSS in `style.css`
- No frameworks, no JavaScript

## Style

- Warm, friendly, simple
- Big readable text
- Must work well on a phone

## Rules

- Keep all files in this folder
- Ask before adding anything new
- Plain language — a neighbour should understand every word
