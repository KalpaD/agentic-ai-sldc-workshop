# Planning and Task Breakdown

Turns an agreed PRD into tasks small enough to finish and check one at a time.

## How to break the work down

1. Read the PRD's requirements. Each one becomes **one or more tasks**.
2. Put the tasks in the order they must happen — nothing may depend on a task
   that comes later.
3. Make each task small enough to finish in one sitting.

## Every task must have

- **A number and a short name** — so we can refer to it
- **What to do** — one or two plain sentences
- **How we know it is done** — something you can look at and confirm

## Output format

```
Task 1 — [short name]
  Do:    [what happens]
  Done:  [what you can check]
```

## Rules

- If a task cannot be checked, it is not a task — rewrite it.
- If a task feels too big to start, split it in two.
- Aim for 4 to 8 tasks. More than that usually means the PRD is too big.
- Do not start building. Produce the list, then stop and let me review it.

## Next step

Work the list one task at a time, confirming each is done before moving on.
